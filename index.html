PUMILI NG MODE

PAANO MAGLARO

Computer

  • W A S D lakad, Shift takbo
  • Mouse para tumingin
  • E o click para kunin ang pusa
  • Esc o P para mag-pause

Cellphone

  • Kaliwang bilog para maglakad
  • I-drag ang kanang bahagi para tumingin
  • KUNIN para kunin ang pusa
  • Mas maganda kapag naka-landscape

Controller

  • Kaliwang stick lakad (pindutin o RT para tumakbo)
  • Kanang stick tumingin
  • A / ✕ kunin ang pusa
  • Start pause · B / ◯ bumalik

Photo mode

  • Sa pause menu, piliin ang PHOTO MODE
  • Lumipad gamit ang W A S D, R pataas, F pababa
  • Enter para kunan ng larawan
  • F3 kahit kailan: FPS at posisyon

Mga tip

  • Kumikinang ang mata ng pusa kapag naiilawan.
  • Makinig sa ngiyaw; kaliwa o kanan ang tunog.
  • Tingnan sa ilalim, sa likod, at sa itaas ng mga bagay.
  • Sa LAGIM: huwag mong alisin ang ilaw sa kanya.
